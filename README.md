# Github-Final-Project

## Project Name
**Simple Interest Calculator**

## Description
The Simple Interest Calculator is a simple Bash-based application that calculates the simple interest earned on a principal amount based on the rate of interest and the time period.

## Purpose
The purpose of this project is to demonstrate basic Git and GitHub operations, including repository creation, version control, branching, merging, and collaboration.

## Formula
Simple Interest is calculated using the following formula:

**Simple Interest = (Principal × Rate × Time) / 100**

## Inputs
- Principal amount
- Annual rate of interest
- Time period

## Technology Used
- Bash Scripting
- Git
- GitHub
